# Registro de Notas - 
Aplicación Android desarrollada en Kotlin y Jetpack Compose para el cálculo del promedio ponderado de notas según pesos específicos por curso.

## Características
- Entrada de notas mediante Sliders (0 a 20).
- Opción de redondeo de promedio mediante Switch.
- Validación con Checkbox de confirmación.
- Muestra de estado mediante Chip de color personalizado.
